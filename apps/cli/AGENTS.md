# CLI architecture

`apps/cli` installs, updates, diagnoses, backs up, restores, and operates Context Use deployments.
Commands are user-facing adapters over operational services.

- `src/commands/` mirrors the CLI command tree. A command parses input, invokes one operation, and
  renders its result.
- AWS, Terraform, release, deployment, backup, Nango, and local-process mechanics live in named
  modules outside command files.
- All subprocesses go through the shared process boundary so tests can record exact invocations.
- Never place a secret in an argument, log line, thrown message, generated plan, or test snapshot.
- Model resumable operations as explicit state transitions. A retry must converge rather than repeat
  a destructive step.

Test parsed commands and observable operations. Replace broad source-text regression assertions with
structured configuration parsing or an executable boundary whenever practical.

`src/command-tree.gen.ts` is generated by `bun run codegen`; never edit it manually.
